同期のしかた / How to sync
  • QR: 送る側で SHOW QR、受け取る側で SCAN QR。コードが複数枚なら自動で切り替わるので、全部そろうまで映し続けるだけ。逆方向も同様にすると両方が同じ内容になります。
  • LAN: PCで kwnote serve を実行し、表示されたQRをスマホのカメラで読むと、このアプリがそのPCから開き自動で同期されます。PCのブラウザは http://localhost:7878 を開くだけ。
  • テキスト / ファイル: COPY CODE / SAVE FILE で書き出し、相手側の LOAD / OPEN FILE で読み込み。メッセージアプリやAirDropでも送れます。
  • 読み込みはすべてマージです（新しく更新された方が勝ち、削除も伝わります）。
